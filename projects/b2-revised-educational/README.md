It uses text, relevant outline illustrations, and the original synthesized instrumental bed. No synthetic narration or new speech attributed to the presenter. No footage zoom. It does not claim or guarantee approval by TikTok.

The original B2 output is preserved separately. Use this alternative's matching neutral description; it is not a lender advertisement with disguised keywords.

## Rebuild

Requires Node >=22, FFmpeg, Python with Pillow. Place the supplied project's original `music-original.wav` from B2 in this folder, then run `bash prepare.sh`, `npm run check`, and `npm run render`. The short music clip is included in the project for direct rendering. Font supplied under OFL; GSAP bundled.

Technical validation is in `validation.json`. Editorial changes and scene timings are in `edit-plan.json`.
