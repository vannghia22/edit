## Rebuild and verification

Place the uploaded b (2).mp4 here as `source.mp4`. Run `bash prepare.sh`, `npm run check`, then `npm run render`. Requires Node >=22, FFmpeg and Python with NumPy/Pillow. HyperFrames pinned to 0.8.181. Font is supplied under OFL in OFL.txt.

`edit-plan.json` records the latest user override and timings. `audio-audit.json` records the mix. `validation.json` records full decode, A/V timing, source preservation and technical checks. Transcription was compared across local recognizers and obvious phonetic mistakes corrected; no direct auditory review or forced alignment is claimed.
